A single page that exercises every prose element, so styling regressions are easy
to spot at a glance. Like the welcome note, this is **development-only** scaffolding
and never reaches production.

## Headings and paragraphs

Body copy sits at a comfortable reading measure with generous line height. Inline
formatting includes **bold**, *italic*, and [a link](/services) back into the site.

### A third-level heading

Third-level headings step down in size while staying in the serif family, so the
hierarchy reads clearly without shouting.

## Lists

An unordered list:

- First point, kept to a single clear idea
- Second point, with a little more supporting detail
- Third point to close

An ordered list:

1. Discovery — understand the operating problem
2. Design — shape the approach
3. Delivery — put it to work

## Quotes and code

> A blockquote pulls out a key line without needing a bigger heading to carry it.

Inline `code` sits mid-sentence, and a fenced block handles longer snippets:

```js
const margin = revenue - cost;
if (margin < baseline) flag('review');
```
